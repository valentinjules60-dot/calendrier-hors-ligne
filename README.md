# Calendrier hors ligne

Calendrier installable sur ordinateur et tablette. Les rendez-vous sont gardés sur l’appareil et peuvent être synchronisés entre appareils avec Supabase.

Pour activer la synchronisation, suis le [guide pas à pas Supabase](https://github.com/valentinjules60-dot/calendrier-hors-ligne/blob/main/supabase/SETUP.md).
